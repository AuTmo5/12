编程平台：STEP 7-Micro/WIN SMART V2.8（S7-200 SMART CPU ST20）
假设条件：按钮为自复位常开型（带硬件RC滤波）；指示灯为 24VDC LED（≤20mA）；CPU 为 ST20 晶体管输出，公共端接 0V；若使用 SR20 继电器输出，可接 24VDC 或 220VAC 负载。

一、实验目的

  1. 掌握西门子 S7-200 SMART 位逻辑指令（S / R 置位复位、= 输出线圈）的使用方法。
  2. 理解"单灯互锁"控制逻辑的两种实现思路——逐位互锁法与数据传送法。
  3. 掌握字节传送指令（MOV_B）在批量输出控制中的应用。
  4. 学会使用符号表（Symbol Table）规范编程，提高程序可读性。
  5. 掌握上电初始化（首次扫描位 SM0.1）的编程方法，避免上电随机输出。
  6. 培养调试与排错能力，能够识别并解决双线圈冲突、输出公共端接线错误等常见问题。

程序采用循环扫描方式，每个扫描周期依次检测 I0.0~I0.7 与 I1.0。检测到按钮按下时执行对应互锁输出逻辑；无按钮按下时保持当前输出（S/R 指令具有锁存功能）。

五、梯形图程序设计

方案 A：逐位互锁法

设计思路：每个输入按钮对应一个输出支路。按下 SBn 时，先用 RST 指令复位所有其他输出位，再用 SET 指令置位第 n 个输出位。S/R 指令具有锁存保持功能，按钮松开后输出状态保持不变。

Network 1：上电初始化

  SM0.1
──┤ ├────────────────────[ R  QB0, 8 ]
                       复位 QB0 起 8 位

SM0.1 为首次扫描标志，PLC 上电进入 RUN 后第一个扫描周期为 ON。R 指令将 QB0 起的 8 个位全部清零，确保上电时 8 灯全灭。

Network 2：按下 SB1 → 仅 HL1 亮

  I0.0
──┤ ├──────┬────────────[ R  QB0, 8 ]
           │            复位全部 8 位
           └────────────[ S  Q0.0, 1 ]
                        置位 HL1

Network 3 ~ Network 9：SB2 ~ SB8 同理

  I0.1
──┤ ├──────┬────────────[ R  QB0, 8 ]
           └────────────[ S  Q0.1, 1 ]   // HL2

  I0.2
──┤ ├──────┬────────────[ R  QB0, 8 ]
           └────────────[ S  Q0.2, 1 ]   // HL3

  ...（SB4 ~ SB7 依此类推）

  I0.7
──┤ ├──────┬────────────[ R  QB0, 8 ]
           └────────────[ S  Q0.7, 1 ]   // HL8

Network 10：按下 SB0 → 全部熄灭

  I1.0
──┤ ├────────────────────[ R  QB0, 8 ]
                       复位全部 8 个输出位
关键截图说明位置：Network 1 应显示 SM0.1 常开触点后接 R(QB0, 8)；Network 2 应显示 I0.0 后分支为两路——上路 R(QB0, 8)、下路 S(Q0.0, 1)。在线监控时在状态表中监控 Q0.0~Q0.7，按 SB3 应仅 Q0.2=1。

方案 B：数据传送法

设计思路：8 个输出位对应 QB0 字节的 8 个位。数字 1~8 分别对应十进制值 1、2、4、8、16、32、64、128（即 2n-1）。按下 SBn 时用 MOV_B 将对应数值写入 QB0，一次性设定所有 8 位状态。例如写入 2（0000_0010）则 Q0.1=1，其余为 0，HL2 亮。

──┤ ├────────────────────[ MOV_B ]
                       IN  : 0
                       OUT : QB0

IF "SB1" THEN
    "QB0" := 1;      // 0000_0001 → HL1
ELSIF "SB2" THEN
    "QB0" := 2;      // 0000_0010 → HL2
ELSIF "SB3" THEN
    "QB0" := 4;      // 0000_0100 → HL3
ELSIF "SB4" THEN
    "QB0" := 8;      // 0000_1000 → HL4
ELSIF "SB5" THEN
    "QB0" := 16;     // 0001_0000 → HL5
ELSIF "SB6" THEN
    "QB0" := 32;     // 0010_0000 → HL6
ELSIF "SB7" THEN
    "QB0" := 64;     // 0100_0000 → HL7
ELSIF "SB8" THEN
    "QB0" := 128;    // 1000_0000 → HL8
ELSIF "SB0" THEN
    "QB0" := 0;      // 全部熄灭
END_IF;
SCL 说明：S7-1200 的 SCL 中 "QB0" 可直接按字节赋值。多个 IF/ELSIF 条件同时为真时，只有第一个满足的分支被执行（优先级从高到低），天然实现了互锁。若需更严格的互锁保证，可使用 CASE 语句。

七、调试步骤与排错指南

7.1 调试步骤

第一步：离线检查

  1. 检查梯形图程序是否有语法错误（Micro/WIN SMART 编译时会自动提示）。
  2. 确认符号表已正确建立，所有地址与符号的对应关系无误。
  3. 检查是否存在双线圈冲突（同一 Q 点被多个线圈驱动）。

第二步：接线检查（断电状态）

  1. 用万用表通断档检查按钮接线：SB1~SB8 一端接 I0.0~I0.7，另一端接 1M（输入公共端）。
  2. SB0 一端接 I1.0，另一端接 1M。
  3. HL1~HL8 一端接 Q0.0~Q0.7，另一端接 24V DC（或 0V，取决于输出类型）。
  4. 确认 PLC 输出公共端（1L/2L 等）已接对应电源。

第三步：下载程序

  1. 使用以太网线或 USB/PPI 电缆连接 PLC 与电脑。
  2. 在 Micro/WIN SMART 中设置通信接口，搜索 CPU。
  3. 将程序下载到 PLC，将 CPU 切换到 RUN 模式。

第四步：在线测试

  1. 打开状态表（Status Chart），添加 Q0.0~Q0.7 监控。
  2. 依次按下 SB1~SB8，观察对应灯是否点亮。
  3. 在 HL 亮时按其他按钮，验证互锁功能。
  4. 按 SB0 验证全部复位。

7.3 重点排错：双线圈冲突

在梯形图编程中，同一 Q 点在程序中只能出现一次输出线圈（ ）。如果同一 Q 点被两个或以上的线圈驱动，只有最后一个线圈的状态有效，前面的输出会被覆盖。

本实验中的双线圈风险：

  • 方案 B 中，若同时在 Network 1 和 Network 3 中对 QB0 使用 MOV_B，程序可正常运行（MOV_B 写整个字节，不构成位双线圈）。但若某处用 = Q0.0，另一处用 MOVB 写入 QB0，则 MOVB 会覆盖 = Q0.0 的状态。
  • 方案 A 中，S/R 指令不构成双线圈问题，因为 S 和 R 是置位/复位操作，不是输出线圈。

避免双线圈的方法：

  1. 优先使用 S/R 指令或字节传送指令。
  2. 如果必须用输出线圈，确保同一 Q 点在程序中只出现一次。
  3. 使用中间变量（M）进行逻辑运算，最后统一输出。

7.4 重点排错：QB0 整体写入与位操作的冲突

当程序中同时存在对 QB0 的字节写入（如 MOV_B）和对 Q0.n 的位操作（如 S Q0.0, 1）时，需要注意执行顺序：

  • MOV_B 在后：会覆盖之前所有位操作的结果。
  • 位操作在后：只修改对应位，不影响其他位。
建议：同一程序中不要混用字节写入和位写入来驱动同一组输出。如必须混用，确保位操作在字节写入之后执行，且只用于需要单独调整的位。使用 S/R 指令不受此限制。

7.5 输出公共端接线与电压匹配

CPU ST20（晶体管输出，DC/DC/DC）：

  • 输出类型：晶体管源型输出，输出公共端（1L、2L 等）接 0V。
  • 负载电压：24V DC。
  • 每点额定电流：0.5A，所有输出点总电流有限制。
  • 不能直接驱动 220V AC 负载。

CPU SR20（继电器输出，AC/DC/Relay）：

  • 输出类型：继电器触点，可接 24V DC 或 220V AC。
  • 每点额定电流：2A。
  • 输出公共端根据负载类型选择接 24V DC 或 220V AC 的 L/N。
注意事项：若使用 SR20 接 220V AC 指示灯，务必做好绝缘防护，并确保输出公共端接线正确。ST20 晶体管输出有漏电流（约 10μA），极低功率的 LED 指示灯可能微弱发光，可并联假负载电阻解决。

九、思考题

思考题 1：如何改为"按住才亮，松开即灭"？

将程序中的 S（置位）指令改为 = 输出线圈即可。例如方案 A 中 Network 2 改为：

  I0.0
──┤ ├────────────────────( ) Q0.0

此时 Q0.0 直接由 I0.0 驱动，按下亮、松开灭。但需注意互锁逻辑：如果 Q0.0~Q0.7 均由各自的 I 点直接驱动，多个按钮同时按下时会有多个灯同时亮。如需保持互锁，可在每个输出支路串联其他 7 个按钮的常闭触点；或者保留 S/R 方案，在末端用 I 点的常闭触点复位。

思考题 2：如何改为按 1~8 逐个累积点亮？

将复位操作去掉即可。方案 B 中，将每个网络的 MOV_B 改为：读取当前 QB0 的值，与对应数值进行"或"运算后写回：

  I0.1
──┤ ├──────[ MOV_B ]  IN: QB0, OUT: MB0      // 读当前值
           [ OR_B  ]  IN1: MB0, IN2: 2, OUT: MB0   // 与 2 做或运算
           [ MOV_B ]  IN: MB0, OUT: QB0      // 写回

或者直接用 S 指令（不加 R）：按下 SBn 时只 S Q0.n, 1，不执行任何 R 操作。这样每次按下新按钮，新灯亮，旧灯保持亮。SB0 用于全部复位。

思考题 3：如何用 3 个输入按钮编码表示 8 个数字？

使用 3 个按钮作为二进制输入的 3 位，分别代表 1、2、4 的权重。将 3 个输入组合成 3 位二进制数（000~111），通过译码得到 8 个数字。具体实现：

// 将 I0.0~I0.2 组合为 3 位二进制值
LD     I0.0
MOVB   1, MB0
LD     I0.1
MOVB   2, MB1
LD     I0.2
MOVB   4, MB2

更简洁的方法是用加法指令：先将 MB0 清零，然后依次判断 I0.0/I0.1/I0.2，为 ON 时给 MB0 加上 1/2/4。最后将 MB0 的值通过查表或 MOV 指令映射到 QB0。

思考题 4：如何加入数码管显示当前数字？

本实验的 8 个输出对应 8 个灯，如果要加入七段数码管显示数字 1~8，需要额外的 4 个输出点（Q1.0~Q1.3）输出 BCD 码，连接到 BCD-七段译码器（如 74LS47/74LS48），译码器驱动数码管显示对应数字。程序需要在按下 SBn 时，同时将对应的 BCD 码（1~8）写入 Q1.0~Q1.3。可以使用比较指令或查表法实现：

LD     I0.0
MOVB   1, QB1          // 数码管显示 1
LD     I0.1
MOVB   2, QB1          // 数码管显示 2
...

这样，8 个 LED 灯和数码管可以同时显示当前数字，形成双重指示效果。

本文档基于 S7-200 SMART + STEP 7-Micro/WIN SMART V2.8 编写，所有指令均可在该平台中实际运行。
